Descrição detalhada

Entidade que representa uma Pessoa no sistema.

Agrupa os dados de um usuário envolvido nos projetos, sendo unicamente identificada pelo seu Email (Chave Primária). Contém informações de identificação (Nome), credenciais de acesso (Senha) e a função exercida no sistema (Papel).
