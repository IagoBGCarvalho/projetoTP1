Descrição detalhada

Módulo de Serviço de Projeto.

Gerencia as regras de negócio atreladas aos Projetos, Histórias de Usuário e Sprints. Depende da interface IDPR.

overridevirtual

Altera o estado de uma Historia de Usuario (RF 25).

Proprietario de Produto e Mestre Scrum podem realizar esta operacao. Os estados validos sao: A FAZER, FAZENDO e FEITO.

Parâmetros
codigoHistoriaCodigo da Historia de Usuario.
novoEstadoNovo estado a ser atribuido a historia.
Retorna
true Se o estado for alterado com sucesso.
false Se a historia nao for encontrada ou o estado for invalido.

overridevirtual

Cria uma nova Historia de Usuario (RF 13).

Apenas o Proprietario de Produto pode criar historias. A historia deve ser associada a um projeto e criada com estado "A FAZER". A descricao deve seguir o formato: papel (como...), acao (eu quero...) e valor (para...).

Parâmetros
historiaReferencia constante para a entidade HistoriaDeUsuario a ser criada.
Retorna
true Se criada com sucesso.
false Se o codigo ja existir ou o projeto associado nao existir.

Cria um novo projeto no sistema (RF 05).

Apenas o Proprietario de Produto pode criar projetos. Ao criar, o projeto deve ser associado a um Mestre Scrum. A soma das capacidades dos sprints do projeto nao pode exceder o numero de dias entre as datas de inicio e termino.

Retorna
true Se o projeto for criado com sucesso.

◆ moverHistoriaParaSprint()

const Codigo &  codigoSprint 
)
overridevirtual

Move uma Historia de Usuario do backlog do projeto para um Sprint (RF 24).

Apenas o Mestre Scrum pode realizar esta operacao. A historia deve estar atualmente associada ao projeto (e nao a outro sprint). A estimativa da historia somada as estimativas ja existentes no sprint nao pode exceder a capacidade do sprint.

Parâmetros
codigoHistoriaCodigo da Historia de Usuario a ser movida.
codigoSprintCodigo do Plano de Sprint de destino.
Retorna
true Se a movimentacao for bem-sucedida.
false Se a historia ou o sprint nao existirem, ou se a capacidade do sprint for excedida.

Implementa ISP.
