Descrição detalhada

Entidade que representa um Projeto no sistema.

Agrupa as informações fundamentais de um projeto, sendo unicamente identificado por um Código (Chave Primária). Comporta também o Nome do projeto e o seu período de duração (Data de início e Data de término).
